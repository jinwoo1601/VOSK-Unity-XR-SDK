## Known Issues

- **CQB**: VOSK has trouble acoustically matching "cqb" — it's an abbreviation not in VOSK's language model. Options: (1) change slot value to "close quarters", (2) add phonetic aliases in v2.1, (3) test what VOSK actually outputs in free-speech mode when saying "CQB".
- **Cough/noise false matches**: Grammar-constrained VOSK maps coughs and noises to grammar words, triggering false commands. Defer to voice activation (push-to-talk or regex activator) in a future version.

## Logcat Reference

- **Match**: `[CommandDemo] Command: <intent> (confidence=X.XX)` + slot detail line
- **No match**: `[CommandDemo] Unrecognised: "<text>"`
- **Native errors**: `vosk-bridge` tagged messages
