## Demo Changes

`CommandDemo.cs` now includes mode-switching commands in the **common** set:

| Say this               | Intent           | Effect                                            |
|------------------------|------------------|---------------------------------------------------|
| "weapons mode"         | mode_weapons     | Activates weapons + common sets                   |
| "navigation mode"      | mode_navigation  | Activates navigation + common sets                |
| "all modes"            | mode_all         | Activates weapons + navigation + common sets      |
| "disable all"          | mode_disable     | Deactivates all sets; auto-restores in 5 seconds  |

**Key log lines to watch**:
- `[CommandDemo] Active sets: [weapons, common]` — confirms which sets are active after each switch
- `[CommandDemo] Switched to WEAPONS mode` — confirms mode switch completed
- `[CommandDemo] Auto-restored ALL mode` — confirms 5-second restore after disable

### Known Bugs
- **"all" / "fall" VOSK confusion**: When navigation set is active, "all modes" is frequently misrecognized as "fall modes" because VOSK prefers the navigation keyword "fall" (from "fall back from target") over "all". Took 3+ attempts to trigger from navigation mode. Consider alternative phrase (e.g., "enable all") or adding "all" as a standalone grammar hint.

### Notes
- "cease fire" consistently misheard as "safe five" by VOSK when in navigation mode (not in grammar)
- "all modes" consistently misheard as "fall modes" when navigation set active (VOSK prefers "fall" keyword). "enable all" is a reliable alternative.
- Speaking immediately after a mode switch (~50-70ms grammar rebuild) can lose leading words. Wait 1-2s after switch.
- Phase 9: No measurable accuracy difference between full and restricted grammars for tested phrases. May need more ambiguous commands to see benefit.
- "two" word consistently gets conf=0.50 from VOSK regardless of grammar size.

- **Batch**: `[CommandDemo] Batch: N command(s) from single utterance`

- **Active sets**: `[CommandDemo] Active sets: [set1, set2, ...]`
- **Mode switch**: `[CommandDemo] Switched to WEAPONS/NAVIGATION/ALL mode`
- **Disable**: `[CommandDemo] All commands DISABLED — auto-restoring in 5s`
- **Auto-restore**: `[CommandDemo] Auto-restored ALL mode`
- **Debounce suppression**: expected command simply absent from logcat output
